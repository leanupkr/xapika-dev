## 1. 로그인

`https://xapika.pl/studio` 접속 → **공용 계정 `info@xapika.pl`**로
"Continue with Google" 로그인(담당 개발자가 알려준 계정 정보 사용). 이
계정은 회사 전체가 공용으로 쓰는 계정입니다 — 뉴스 글을 다루는 모든 사람이
같은 계정 하나로 로그인합니다. 개인별 별도 계정은 없습니다. 이 주소만
즐겨찾기 해두시면 됩니다.

**계정을 공용으로 쓰는 대신 아래 4가지 규칙을 꼭 지켜주세요**:

1. **이 Sanity 계정에 신용카드를 절대 등록하지 마세요.** 카드 등록을
   요구하는 화면이 나오면 입력하지 말고 바로 담당 개발자에게 알려주세요.
2. **`/studio` 화면만 사용하세요.** 이 계정은 Sanity뿐 아니라 회사 사이트
   호스팅(Vercel)·도메인·이메일 발송까지 관리하는 마스터 계정입니다.
   `sanity.io/manage`나 `vercel.com` 같은 다른 화면에 들어가면 이 뉴스
   CMS와 상관없는 설정이 바뀌거나, 최악의 경우 **사이트 자체가 내려갈 수
   있습니다.** 다른 화면으로 안내받으면 먼저 담당 개발자에게 확인하세요.
3. **Google 계정 2단계 인증을 꺼두지 마세요.**
4. **담당자가 바뀌면 즉시 비밀번호를 바꿔주세요.** 공용 계정이라 "이
   사람만 접근 차단"하는 버튼이 없습니다 — 비밀번호 변경이 유일한 차단
   수단입니다.

## 2. 자체 기사 쓰기 (Own article)

News Post 목록 → **+ Create** 클릭 → **Article type**에서 **Own article
(written by us)** 선택(기본값이라 원래 이게 선택돼 있음) → 아래 칸만
채우면 발행 가능합니다:

| 채워야 할 칸 | 비고 |
|---|---|
| **Title (English — required)** | 제목 |
| **Excerpt (English — required)** | 카드/검색결과에 뜨는 1~3문장 요약 |
| **Category** | 4가지 중 하나 선택 |
| **Body (English)** | 본문 내용 |

**URL slug**와 **Published date**는 자동으로 채워지므로 그냥 두면 됩니다.
**Cover image**는 필수는 아니지만, 없으면 카드가 밋밋해서 넣기를
권장합니다 — 넣으면 **Alt text**(사진 설명) 칸도 같이 채워야 합니다(4번
참고).

## 3. 외부 보도 스크랩하기 (External press coverage)

다른 언론사가 Xapika를 취재/보도한 기사를 소개할 때 씁니다.

> **원문 기사 전체를 절대 복사해서 붙여넣지 마세요.** 저작권 문제가
> 됩니다. 짧은 요약 + 원문으로 가는 링크만 넣습니다.

**+ Create** → **Article type**에서 **External press coverage (link
out)** 선택 → 아래 칸만 채우면 발행 가능합니다:

| 채워야 할 칸 | 비고 |
|---|---|
| **Title (English — required)** | 제목 (보도 기사 제목을 그대로 옮겨도 됨) |
| **Excerpt (English — required)** | 우리가 직접 쓰는 짧은 요약 1~3문장 (원문 그대로 복사 금지) |
| **Category** | 보통 **Media Coverage** 선택 |
| **External article URL** | 그 언론사 기사 페이지 주소 |
| **Source name (e.g. Rynek Kolejowy)** | 매체명 |

이 유형에서는 **Body(본문) 칸 자체가 화면에 나타나지 않습니다** — 애초에
전문을 옮겨 적을 곳이 없다고 이해하시면 됩니다.

## 4. 사진 넣기

- 대표 사진(**Cover image**)이나 갤러리(**Gallery**) 칸에 드래그 앤 드롭
  또는 클릭해서 선택합니다.
- **스마트폰으로 찍은 사진 그대로 올려도 됩니다.** 일반 JPEG는 문제없이
  업로드됩니다.
- 아이폰 **HEIC** 사진이 업로드 안 되면 아이폰 **설정 → 카메라 → 포맷 →
  높은 호환성**으로 바꾼 뒤 다시 시도하세요.
- 업로드 후 사진을 클릭하면 동그란 점(hotspot)이 나옵니다 — 사진에서 가장
  중요한 부분(얼굴, 로고 등)에 맞춰 두면 화면 크기가 바뀌어도 그 부분이
  잘리지 않고 나옵니다.
- **Alt text**(대체 텍스트)란 그 사진을 눈으로 볼 수 없는 사람에게 대신
  읽어주는 한두 문장짜리 설명입니다("정비팀이 화물차량을 점검하는
  모습"처럼 간단히). 검색엔진도 이 문구를 읽습니다. **사진을 넣으면 이
  칸은 필수**이며, 안 채우면 Publish 버튼이 눌리지 않습니다.

## 5. 임시저장 vs 발행의 차이

- **임시저장(Draft, 따로 버튼 없이 자동 저장됨)**: 글을 쓰는 동안 계속
  자동으로 저장됩니다. 이 상태에서는 **아직 아무도 볼 수 없습니다**(사이트에
  공개 안 됨). 며칠에 걸쳐 나눠 써도 안전합니다.
- **Publish(발행)**: 버튼을 누르는 즉시 사이트에 공개됩니다. 7번의 주의사항을
  꼭 먼저 읽어주세요.

## 6. 오타 고치기 · 글 내리기 · 지운 글 되살리기

**오타/내용 고치기**
글을 열어서 수정 → 이미 한 번 **Publish**했던 글이라면, 고친 내용은
자동으로 임시저장만 될 뿐 **사이트에는 반영되지 않습니다.** 화면 위쪽
**Publish** 버튼이 다시 활성화되어 있을 텐데, 그걸 다시 눌러야 실제
사이트에 수정 내용이 반영됩니다.

**글 내리기 — 두 가지 방법, 목적이 다릅니다**
- **Unpublish**: 사이트에서만 안 보이게 숨깁니다. 글 자체와 그동안 쓴
  내용은 그대로 남아있고, 나중에 다시 **Publish**하면 그대로 복구됩니다.
  "일단 잠깐 내려두고 싶다"에 적합합니다.
- **Delete**: 글을 열고 **⋯**(더보기) → **Delete** → 확인. 완전히
  지웁니다. 3일 이내면 아래 방법으로 되돌릴 수 있습니다.

**지운 글 되살리기**
문서 상단 시계 아이콘(**History**)에서 과거 시점을 선택 → **Restore**.
**단, 3일 이내에만 이 버튼이 보입니다.** 3일이 지나면 이 방법으로는 복구가
안 되니, 실수를 발견하면 최대한 빨리 담당 개발자에게 알려주세요(3일이
지나도 별도 백업으로 복구는 가능합니다 — `docs/NEWS_BACKUP.md` 참고).

## 7. 꼭 알아야 할 주의 2가지

**① "Publish"를 누르는 순간, 그 글은 전 세계 누구나 볼 수 있게 됩니다.**
사이트 화면에 링크가 안 걸려 있어도 마찬가지입니다. 나중에 **Unpublish**를
눌러도, 발행되어 있던 동안 이미 노출됐던 사실 자체는 되돌릴 수 없습니다.
**검토가 끝나지 않은 글, 아직 공개할 시점이 아닌 내용은 절대 Publish를
누르지 말고 임시저장(Draft) 상태로만 두세요.**

**② 변경 이력(History)은 3일까지만 되돌릴 수 있습니다.**
3일이 지나면 되돌리기 버튼 자체가 사라집니다. 대신 매일 자동으로 별도
백업이 돌아가고 있으니(`docs/NEWS_BACKUP.md` 참조) 3일이 지나도 복구
자체는 가능하지만, **실수를 발견하면 최대한 빨리(가급적 3일 이내) 담당
개발자에게 알려주세요** — 빠를수록 복구가 훨씬 간단합니다.

## 8. 발행 후 반영 시간

Publish를 누르면 보통 몇 초 안에 사이트에 반영됩니다. **새로고침을 1~2번
해야 보이는 경우가 있는데, 이는 정상 동작입니다.** 1~2분이 지나도 안
보이면 담당 개발자에게 문의하세요.

## 부록 — 자주 겪는 문제

| 증상 | 대처 |
|---|---|
| Publish 버튼이 눌러지지 않음(회색) | 필수 항목 누락 — 화면에 빨간 표시된 필드 확인(사진 있으면 Alt text 필수) |
| 사진 업로드 안 됨 | HEIC면 4번 참고. 용량이 아주 크면 시간이 걸릴 수 있음 |
| 발행했는데 사이트에 안 보임 | 새로고침 1~2회, 그래도 1~2분 이상 안 보이면 개발자에게 문의 |
| 실수로 삭제함 | 바로 개발자에게 알리기 — 3일 이내 History에서 복구 가능 |
| `sanity.io/manage` 같은 낯선 화면이 뜸 | `/studio`가 아닙니다 — 뒤로 가서 `xapika.pl/studio`로 다시 접속, 아무것도 클릭하지 말고 개발자에게 확인 |
