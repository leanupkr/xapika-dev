# Xapika 뉴스 CMS — 국문 요약 (1~2p)

> 자세한 전체 매뉴얼은 영문 정본 `docs/NEWS_CMS_GUIDE.md`입니다. 이 문서는
> 빠르게 훑어보는 치트시트이며, 두 문서 내용이 다르면 영문 정본이 기준입니다.

---

## ⚠️ 반드시 알아야 할 것 2가지

**1. "Publish"(발행)를 누르는 순간, 그 글은 전 세계 누구나 볼 수 있게 됩니다.**
사이트 화면에 링크가 안 걸려 있어도 마찬가지입니다. 나중에 "Unpublish"(발행
취소)를 눌러도, 발행되어 있던 동안 이미 노출됐던 사실 자체는 되돌릴 수
없습니다. **검토가 끝나지 않은 글, 아직 공개할 시점이 아닌 내용은 절대
Publish를 누르지 말고 임시저장(Draft) 상태로만 두세요.**

**2. 실수로 삭제하거나 잘못 고쳤을 때, "되돌리기"는 3일까지만 됩니다.**
그 이후엔 되돌리기 버튼 자체가 사라집니다. 대신 매일 자동으로 별도 백업이
돌아가고 있으니(`docs/NEWS_BACKUP.md` 참조) 3일이 지나도 복구 자체는
가능하지만, **실수를 발견하면 최대한 빨리(가급적 3일 이내) 담당 개발자에게
알려주세요** — 빠를수록 복구가 훨씬 간단합니다.

## 1. 로그인

`https://xapika.pl/studio` 접속 → **공용 계정 `info@xapika.pl`**로
"Continue with Google" 로그인(담당 개발자가 알려준 계정 정보 사용). 이
계정은 회사 전체가 공용으로 쓰는 계정입니다 — 뉴스 글을 다루는 모든 사람이
같은 계정 하나로 로그인합니다. 개인별 별도 계정은 없습니다. 이 주소만
즐겨찾기 해두시면 됩니다.

**계정을 공용으로 쓰는 대신 아래 4가지 규칙을 꼭 지켜주세요**:

1. **이 Sanity 계정에 신용카드를 절대 등록하지 마세요.** 카드 등록을
   요구하는 화면이 나오면 입력하지 말고 바로 담당 개발자에게 알려주세요.
   카드를 아예 등록하지 않아야 누구도 실수로 요금제를 올리거나 결제가
   발생하는 일이 없습니다.
2. **`/studio` 화면만 사용하세요.** 이 계정은 Sanity뿐 아니라 회사 사이트
   호스팅(Vercel)·도메인·이메일 발송까지 관리하는 마스터 계정입니다.
   `sanity.io/manage`나 `vercel.com` 같은 다른 화면에 들어가면 이 뉴스
   CMS와 상관없는 설정이 바뀌거나, 최악의 경우 **사이트 자체가 내려갈 수
   있습니다.** 다른 화면으로 안내받으면 먼저 담당 개발자에게 확인하세요.
3. **Google 계정 2단계 인증을 꺼두지 마세요.** 공용 계정일수록 유출됐을
   때 피해가 커서, 2단계 인증은 선택이 아니라 필수입니다.
4. **담당자가 바뀌면 즉시 비밀번호를 바꿔주세요.** 공용 계정이라 "이
   사람만 접근 차단"하는 버튼이 없습니다 — 비밀번호 변경이 유일한 차단
   수단입니다. 담당자 교체가 있을 때마다 담당 개발자에게 알려 진행하세요.

`sanity.io/manage`라는 다른 화면은 절대 들어가실 필요 없습니다 — 결제·삭제
버튼이 있는 개발자 전용 화면입니다.

## 2. 새 글 쓰기

News Post 목록 → **+ Create** 클릭 → 맨 위 **Article type**(글 종류)에서
선택:

- **Own article (written by us)** — 우리가 직접 쓰는 글. 본문을 Studio
  안에서 직접 작성합니다.
- **External press coverage (link out)** — 외부 언론이 우리에 대해 쓴
  기사. 전문을 복사하지 말고 짧은 요약 + 원문 링크만 넣습니다.

공통 입력 항목:

| 화면 필드명 | 뜻 |
|---|---|
| Title (English — required) | 제목(영어, 필수) |
| URL slug | 웹주소용 문자열 — 보통 자동생성 그대로 두면 됨 |
| Excerpt (English — required) | 카드/검색결과에 뜨는 1~3문장 요약(필수) |
| Category | 분류 (Company News / Project Update / Press Release / Media Coverage) |
| Published date | 발행일 (기본값: 지금) |
| Cover image | 대표 사진 |
| Alt text | 사진 설명 문구 — 사진을 넣으면 필수 입력 |
| Body (English) | 본문 (자체 작성 글만 해당) |
| External article URL / Source name | 외부 기사 링크 / 매체명 (외부 기사만 해당) |

전문 용어 대조표는 `docs/NEWS_UI_KOREAN_GLOSSARY.md`를 참고하세요.

## 3. 사진 업로드

드래그 앤 드롭 또는 클릭해서 선택. 일반 JPEG는 그대로 됩니다. 아이폰
HEIC 사진이 업로드 안 되면 아이폰 **설정 → 카메라 → 포맷 → 높은 호환성**으로
바꾼 뒤 다시 시도하세요. 업로드 후 사진을 클릭하면 나오는 동그란
점(hotspot)을 사진에서 가장 중요한 부분(얼굴, 로고 등)에 맞춰 두세요.

## 4. 임시저장 vs 발행

- **임시저장(따로 버튼 없이 자동 저장됨)**: 아직 비공개. 글 쓰는 중일 때.
- **Publish(발행)**: 즉시 사이트에 공개. 위 경고 1번 다시 확인 후 클릭.

## 5. 수정 · 삭제

- **수정**: 글 열고 수정 → 이미 발행된 글이면 **Publish** 버튼이 다시
  활성화됨 → 눌러야 실제 사이트에 반영됩니다.
- **삭제**: 글 열고 **⋯**(더보기) → **Delete** → 확인. 3일 이내면 문서 상단
  시계 아이콘(History)에서 되돌리기 가능.

## 6. 상단 고정(Featured)

**Pin to top of list** 토글을 켜면 그 글이 목록 맨 위에 고정됩니다. 한
번에 하나만, 정말 중요한 발표에만 사용하세요.

## 7. 한국어 토글

**Title (Korean)**, **Excerpt (Korean)**, **Body (Korean)** 세 필드 중
하나라도 채우면 그 글 상세페이지에 EN/KO 전환 버튼이 자동으로 생깁니다.
안 채우면 전환 버튼 자체가 안 보입니다 — 별도 설정 필요 없음.

## 8. 발행 후 반영 시간

Publish를 누르면 보통 몇 초 안에 사이트에 반영됩니다. **새로고침을 1~2번
해야 보이는 경우가 있는데, 이는 정상 동작입니다.** 1~2분이 지나도 안
보이면 담당 개발자에게 문의하세요.

## 9. 신규 담당자 초대

이 문서를 읽는 분은 직접 초대할 수 없습니다 — 계정 소유자(`info@xapika.pl`)
또는 담당 개발자가 `sanity.io/manage` → Members → Invite에서 **Project
Administrator** 권한으로 초대해야 합니다. 상세 절차는
`docs/NEWS_CMS_GUIDE.md` §8을 참고하세요.

## 10. 자주 겪는 문제

| 증상 | 대처 |
|---|---|
| Publish 버튼이 눌러지지 않음(회색) | 필수 항목 누락 — 화면에 빨간 표시된 필드 확인(사진 있으면 Alt text 필수) |
| 사진 업로드 안 됨 | HEIC면 위 3번 참고. 용량이 아주 크면 시간이 걸릴 수 있음 |
| 발행했는데 사이트에 안 보임 | 새로고침 1~2회, 그래도 1~2분 이상 안 보이면 개발자에게 문의 |
| 실수로 삭제함 | 바로 개발자에게 알리기 — 3일 이내 History에서 복구 가능 |
| `sanity.io/manage` 같은 낯선 화면이 뜸 | `/studio`가 아닙니다 — 뒤로 가서 `xapika.pl/studio`로 다시 접속, 아무것도 클릭하지 말고 개발자에게 확인 |
